# Полная проверка функционала Nexa VPN

---

## Разбор ваших трёх вопросов

### 1. «Три экрана при запуске» — это нормально

Это **онбординг**: 3 приветственных слайда. Показывается **только один раз** — после нажатия «Начать» или «Пропустить» больше не появится.

Хотите увидеть снова — очистите данные приложения:
Настройки телефона → Приложения → nexa_vpn → Хранилище → **Очистить данные**.

### 2. «Не работает регистрация» — дело не в коде

Я проверил backend вживую — регистрация отвечает корректно:

| Запрос | Ответ |
|---|---|
| Новая почта + `Test1234` | **201, токен выдан** |
| Та же почта повторно | 409 «Email already registered» |
| Пароль без цифры | 400 «password must contain a digit» |
| Пароль короче 8 | 400 |

Значит телефон **не достучался до сервера**. Три причины по частоте:

1. **Backend не запущен** на компьютере.
2. **Брандмауэр Windows** блокирует порт 3000.
3. **Неверный IP** в команде сборки (меняется после перезагрузки роутера).

**Проверка за 10 секунд:** откройте на телефоне в браузере
`http://ВАШ_IP:3000/api/health`
Должно вернуться `{"status":"ok"}`. Если не открылось — приложение тоже не подключится, и дело в пунктах выше, а не в приложении.

**Важно:** если пароль был без цифры или короче 8 символов — приложение покажет ошибку валидации, и это правильное поведение. Требования: **минимум 8 символов, хотя бы одна буква и одна цифра.** Например `Test1234`.

### 3. База была пустой — теперь заполнена

Не было ни планов, ни серверов, ни админа. Я запустил `seed` — теперь есть 6 серверов, 4 тарифа и два аккаунта.

## Запуск на вашем компьютере

Нужно **три терминала** в Android Studio (кнопка `+` рядом с вкладкой Terminal).

### Терминал 1 — база и данные

Выполнить **один раз**, чтобы появились серверы, тарифы и админ:

```powershell
cd backend
npx prisma migrate deploy
npx prisma db seed
```

Ожидаемый вывод последней команды:
```
Seed complete: admin@nexavpn.app / admin1234, user@nexavpn.app / user1234, 6 servers.
```

### Терминал 2 — backend (API)

```powershell
cd backend
npm run start:dev
```

Ждать строку: `Nexa VPN API ready → http://localhost:3000/api`
**Не закрывать.**

### Терминал 3 — админ-панель

```powershell
cd admin
npm run dev
```

Ждать: `Local: http://localhost:3001`
**Не закрывать.**

## Вход в админ-панель

Открыть в браузере **на компьютере**: **http://localhost:3001**

Войти: `admin@nexavpn.app` / `admin1234`

### Что там есть

| Раздел | Что проверить |
|---|---|
| **Dashboard** | Всего пользователей, онлайн, активные premium, серверы |
| **Users** | Список, блокировка/разблокировка, выдача premium |
| **Servers** | 6 серверов, включение/отключение |
| **Plans** | 4 тарифа (30/90/365 дней, Lifetime) |
| **Keys** | Ключи доступа пользователей |
| **Subscriptions** | Активные подписки |
| **Transactions** | История платежей |
| **Banners** | **Новое из #020:** создание баннеров, показы/клики/CTR, слоты Home и Premium, кнопка Reset |
| **Analytics** | Обзор, по дням, популярные серверы |

### Проверка баннеров (задача #020)

1. Админка → **Banners** → «+ Create banner».
2. Заполнить: Title, Description, Button text, **Target URL** (`https://example.com`), **Placement** = Home.
3. Открыть приложение на телефоне → на главном экране появится баннер **крупной картинкой**.
4. Нажать на кнопку баннера → откроется ссылка.
5. Вернуться в админку, обновить страницу → **счётчики показов и кликов выросли, посчитан CTR**.

Если поставить Placement = **Premium**, баннер появится внизу экрана Premium — это второе рекламное место.

## Проверка приложения на телефоне

### Работает

- **Онбординг** — 3 слайда, свайпы (вы подтвердили — работают).
- **Регистрация** — почта + пароль (8+ символов, буква и цифра).
- **Вход** — `user@nexavpn.app` / `user1234`.
- **Язык** — Настройки → ПРИЛОЖЕНИЕ → Язык: Системный / English / Русский.
- **Серверы** — список из 6 стран, фильтры.
- **Premium** — 4 тарифа, оформление, mock-оплата.
- **Мой доступ** — ключ, VLESS-конфиг, QR-код, копирование, «Поделиться».
- **Профиль, Настройки, Уведомления, О приложении, Поддержка.**
- **Баннеры** — со счётчиками.

### Не работает — и не должно на этом этапе

- **Само VPN-подключение.** Кнопка проиграет анимацию и покажет «Подключено», но трафик не идёт и IP не меняется. Внутри заглушка `MockTunnelManager`. Реальный движок — задача #024, для неё нужна зарубежная VPS с Xray.
- **Оплата настоящими деньгами.** Сейчас mock. Боевая YooKassa — после оформления юрлица.
