## 🏗️ АРХИТЕКТУРА СИСТЕМЫ БЛОКИРОВОК

### ТСПУ (Технические Средства Противодействия Угрозам)

**Что это:** DPI-система, установленная на всех узлах связи РФ (100% покрытие с августа 2023)

**Функции:**
- ✅ Блокировка сайтов по ЕГР (Единый государственный реестр)
- ✅ Блокировка VPN/прокси протоколов
- ✅ SNI-инспекция (анализ имени сервера в TLS)
- ✅ TLS Fingerprinting (отпечатки TLS-рукопожатий)
- ✅ Поведенческий анализ трафика
- ✅ QoS-ограничения (замедление трафика)
- ⚠️ Анализ DPI по протоколам (частично)

**Производительность:**
- Пропускная способность узла: ~100 Гбит/с
- Количество правил фильтрации: ~2.5 миллиона
- План к 2030: 954 Тбит/с (в 2.5 раза больше текущего)

**Как работает:**
```
Пользователь → Провайдер → ТСПУ (DPI) → Анализ → Решение
                                              ↓
                                    ┌─────────┴──────────┐
                                    │ VPN обнаружен       │
                                    │ → Блокировка IP     │
                                    │ → Throttling        │
                                    │ → Сброс соединения  │
                                    │ → Заморозка 120 сек │
                                    └─────────────────────┘
```

## 🎯 МЕТОДЫ БЛОКИРОВОК (от простых к сложным)

### Метод 1: Блокировка по IP-адресам
**Принцип:** База известных IP VPN-серверов

**Эффективность:**
- ✅ Высокая для публичных VPN (NordVPN, ExpressVPN)
- ❌ Низкая для self-hosted (твой сервер)

**Обход:**
- Использовать VPS с "чистым" IP (не из базы РКН)
- Менять IP при блокировке
- Использовать residential IP

**Статус в 2026:** Работает, но легко обходится

---

### Метод 2: Портовый анализ
**Принцип:** Блокировка стандартных VPN-портов (1194, 500, 4500)

**Эффективность:**
- ❌ Очень низкая (DPI смотрит содержимое, не порт)

**Обход:**
- Использовать нестандартные порты
- Port 443 (HTTPS) - приоритетная проверка DPI
- High ports (47000+) - 80% пакетов проходят!

**Статус в 2026:** Не работает как основной метод

---

### Метод 3: DPI (Deep Packet Inspection)
**Принцип:** Глубокий анализ содержимого пакетов

**Что анализируется:**
- Заголовки пакетов
- Сигнатуры протоколов (OpenVPN, WireGuard)
- Паттерны шифрования

**Эффективность:**
- ✅ Высокая для старых протоколов (OpenVPN, WireGuard)
- ⚠️ Средняя для VLESS без маскировки
- ❌ Низкая для VLESS + Reality

**Обход:**
- VLESS + Reality (маскировка под HTTPS)
- XHTTP транспорт (маскировка под HTTP-трафик)
- Фрагментация пакетов (частично работает)

**Статус в 2026:** Основной метод, но обходится

---

### Метод 4: SNI-инспекция
**Принцип:** Анализ имени сервера в TLS ClientHello (открытый текст)

**Как работает:**
```
Клиент → TLS ClientHello (SNI: vpn.example.com) → ТСПУ видит SNI → Блокировка
```

**Эффективность:**
- ✅ Очень высокая (SNI передаётся в открытом виде)
- 100% блокировка если SNI в чёрном списке

**Обход:**
- **Empty SNI** - работает в 100% случаев!
- Подмена SNI на белый домен (yandex.ru, vk.com)
- Использование Reality (угон чужого TLS-сертификата)

**Статус в 2026:** Ключевой метод блокировки, но есть обходы

---

### Метод 5: TLS Fingerprinting
**Принцип:** Анализ отпечатков TLS-рукопожатия (JA3/JA4)

**Что анализируется:**
- Версия TLS
- Cipher suites
- Extensions
- Порядок параметров

**Эффективность:**
- ✅ Очень высокая (уникальный отпечаток для каждого клиента)
- Отличает Xray/Sing-Box от Chrome/Firefox

**Обход:**
- Подмена fingerprint на Chrome/Safari
- Настройка `fp=chrome` в Xray
- Использование NaiveProxy (реальный стек Chromium)

**Статус в 2026:** Очень эффективен, сложно обойти полностью

---

### Метод 6: Поведенческий анализ
**Принцип:** Анализ паттернов трафика (не содержимого)

**Что анализируется:**
- Размер пакетов (MTU)
- Временные характеристики (тайминги)
- Асимметрия трафика (upload vs download)
- Количество параллельных соединений

**Эффективность:**
- ✅ Высокая для всех протоколов
- ⚠️ Сложно настроить без ложных срабатываний

**Пример "Сибирской блокировки" (Июнь 2026):**
```
Если:
1. IP в подозрительной подсети
2. Fingerprint Chrome/Safari/iOS
3. >3 параллельных TLS-сессий к одному SNI за 60 сек (интервал <20-50 мс)

Тогда: Заморозка всех TLS-соединений на 120 секунд
```

**Обход:**
- Ограничение количества соединений (`max_connections: 1`)
- Использование gRPC или XHTTP транспорта
- Randomization таймингов
- Снижение асимметрии трафика

**Статус в 2026:** Новый метод, постоянно совершенствуется

### Уровень 1: Базовый (не работает в 2026)

 **Смена порта**
- DPI смотрит содержимое, не порт
- Работает только для high ports (47000+) - 80% успех

❌ **Простые прокси (HTTP/SOCKS5)**
- Легко детектируются по сигнатурам
- Заблокированы с декабря 2025

 **OpenVPN без обфускации**
- Заблокирован полностью с февраля 2026
- Сигнатуры хорошо известны ТСПУ

❌ **WireGuard без AmneziaWG**
- Заблокирован полностью с февраля 2026
- Уникальный fingerprint легко детектируется

---

### Уровень 2: Средний (работает частично)

⚠️ **AmneziaWG (модифицированный WireGuard)**
- Обфускация сигнатур WireGuard
- Работает в некоторых регионах
- Уязвим к поведенческому анализу

⚠️ **VLESS без Reality**
- Маскировка под TLS
- Уязвим к TLS Fingerprinting
- Блокируется с декабря 2025

️ **Фрагментация пакетов**
- Разделение TLS ClientHello на части
- Современные ТСПУ умеют собирать фрагменты
- Эффективность снижается

---

### Уровень 3: Продвинутый (работает в 2026)

✅ **VLESS + Reality + Vision**
- **Reality:** Угон чужого TLS-сертификата (Apple, Microsoft, Яндекс)
- **Vision:** Шифрование на уровне протокола (VLESS Encryption)
- **Эффективность:** 98-99% обхода (начало 2026)
- **Проблема:** Массовая блокировка в мае 2026

**Как работает Reality:**
```
Клиент → TLS handshake с icloud.com (реальный сервер Apple)
         ↓
ТСПУ видит настоящий сертификат Apple → Пропускает
         ↓
После handshake → Данные туннеля вшиваются в сессию
```

✅ **XHTTP транспорт**
- Наследник SplitHTTP и WebSocket
- Маскировка под HTTP-трафик
- Поддержка HTTP/2 и HTTP/3
- Работает через CDN (Cloudflare)

✅ **Empty SNI**
- Установка SNI в пустое значение
- **Работает в 100% случаев!**
- ТСПУ не может сопоставить с чёрным списком

✅ **High ports (47000+)**
- ТСПУ приоритетно проверяет порт 443
- Высокие порты получают только поверхностную проверку
- **80% пакетов проходят**

### Уровень 4: Максимальный (рекомендуется)

 **VLESS + Reality + Vision + XHTTP**

**Конфигурация:**
```json
{
  "protocol": "vless",
  "settings": {
    "encryption": "vision",
    "flow": "xtls-rprx-vision"
  },
  "streamSettings": {
    "network": "xhttp",
    "security": "reality",
    "realitySettings": {
      "serverName": "icloud.com",
      "fingerprint": "chrome",
      "shortId": "xxxxxxxx",
      "publicKey": "xxxxx"
    },
    "xhttpSettings": {
      "mode": "auto",
      "maxUploadSize": 1000000,
      "maxConcurrentUploads": 1
    }
  }
}
```

**Почему работает:**
1. **Reality** - закрывает детекцию на уровне TLS-рукопожатия
2. **Vision** - шифрует данные после handshake (защита от поведенческого анализа)
3. **XHTTP** - маскирует поведение соединения под HTTP
4. **Chrome fingerprint** - обходит TLS Fingerprinting
5. **max_connections: 1** - обходит "Сибирскую блокировку"

**Эффективность:** ~95-98% в сентябре 2026

🏆 **NaiveProxy (альтернатива)**

**Плюсы:**
- Трафик неотличим от Chrome
- Нет уникального fingerprint
- Проходит все проверки ТСПУ

**Минусы:**
- Медленнее чем VLESS
- Сложнее в настройке
- Меньше функций

**Эффективность:** ~90-95%

## 🎯 ГЛАВНЫЕ ВЫВОДЫ

### Что работает в сентябре 2026:

✅ **VLESS + Reality + Vision + XHTTP** - золотой стандарт (95-98% обхода)

✅ **Empty SNI** - 100% обход SNI-инспекции

✅ **High ports (47000+)** - 80% пакетов проходят

✅ **Chrome fingerprint** - обход TLS Fingerprinting

✅ **max_connections: 1** - обход "Сибирской блокировки"

### Что НЕ работает:

❌ OpenVPN, WireGuard, SOCKS5 - заблокированы полностью

❌ VLESS без Reality - блокируется с декабря 2025

❌ Смена порта как единственный метод - DPI смотрит содержимое

❌ Бесплатные VPN - их IP в базе РКН

### Ключевой принцип:

**Не существует "серебряной пули" против ТСПУ.**

Нужна **многоуровневая защита**:
1. Reality (TLS-уровень)
2. Vision (протокол-уровень)
3. XHTTP (транспорт-уровень)
4. Chrome fingerprint (идентификация)
5. Empty SNI (SNI-уровень)
6. High ports (сетевой уровень)

Только комбинация всех методов даёт 95-98% надёжности.
