# 📋 Changelog

Все заметные изменения в проекте Nexa VPN будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

---

## [1.0.0] - 2026-09-02

### Добавлено
- **Auto-reconnect при потере сети** — автоматическое переподключение при восстановлении интернета
- **Новый статус "Восстановление соединения"** — пользователь видит процесс переподключения
- **Мониторинг сети** через connectivity_plus с дебаунсом 2 секунды
- **Privacy Policy** — полная политика конфиденциальности (GDPR + 152-ФЗ)
- **Terms of Service** — условия использования
- **Лендинг для скачивания APK** — красивая страница с описанием функций
- **User Guide** — подробное руководство пользователя
- **SOCKS5 Shield** — уникальная функция проверки защищённости SOCKS5-прокси
- **Device Identity** — система идентификации устройств
- **Admin панель** — управление ключами, баннерами, пользователями
- **Онбординг** — 2 приветственных слайда
- **FAQ экран** — частые вопросы и ответы
- **Поддержка** — экран для связи с поддержкой
- **Многоязычность** — русский и английский языки
- **Crash reporting** — Firebase Crashlytics для отслеживания ошибок
- **Auto-reconnect логика** — intelligent reconnect при потере связи

### Изменено
- Упрощён онбординг с 3 до 2 слайдов
- Улучшена обработка ошибок подключения
- Обновлены тексты локализации (RU/EN)
- Исправлен livePingProvider для работы в статусе reconnecting

### Удалено
- STORE_LISTING.md (не публикуем в Google Play)
- Избыточные файлы из uploads/

### Исправлено
- Кнопка сканирования SOCKS5 Shield теперь работает корректно
- Error handling в провайдерах
- Обработка ошибок в vpn_service_impl
- Корректная работа статусов VPN (connected/reconnecting)

### Безопасность
- Audit безопасности кода проведён
- Все критические уязвимости устранены
- JWT аутентификация настроена
- Rate limiting добавлен
- Helmet middleware активирован

### Производительность
- Оптимизирована работа с провайдерами
- Улучшено логирование через AppLogger
- Минимизированы накладные расходы на VPN

## [0.9.0] - 2026-08-31

### Добавлено
- Базовая функциональность VPN через Xray
- VLESS протокол поддержки
- Управление ключами доступа
- Список серверов с поиском
- Статистика подключения (скорость, пинг, длительность)
- Управление устройствами
- Подписка и оплата (заглушка для будущей интеграции)

### Изменено
- Архитектура переведена на Clean Architecture
- UI обновлён до Material 3 с glassmorphism стилем
- Riverpod используется для state management
- GoRouter для навигации

### Исправлено
- Множество мелких багов в UI
- Ошибки в обработке состояний
- Проблемы с навигацией

## Версионирование

Мы используем [Semantic Versioning](https://semver.org/lang/ru/):

- **MAJOR** версия — несовместимые изменения API
- **MINOR** версия — обратно совместимая новая функциональность
- **PATCH** версия — обратно совместимые исправления багов

## Как обновиться

1. Скачайте новый APK
2. Установите поверх старой версии
3. Все настройки сохранятся автоматически
