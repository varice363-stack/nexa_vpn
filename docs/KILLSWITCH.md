# 🔒 Kill Switch — Документация

## Что такое Kill Switch?

**Kill Switch** (аварийное отключение) — это функция безопасности которая блокирует весь интернет-трафик если VPN-соединение внезапно разрывается.

### Зачем нужен?

Без Kill Switch когда VPN отваливается:
- ❌ Ваш реальный IP-адрес становится видимым
- ❌ Весь трафик идёт в открытом виде
- ❌ Приложения могут передать данные без шифрования
- ❌ Вы даже не заметите что VPN отключился

С Kill Switch:
- ✅ При разрыве VPN весь интернет блокируется
- ✅ Ваш IP не раскрывается
- ✅ Данные не передаются в открытом виде
- ✅ Вы сразу видите предупреждение

---

## Как это работает в Nexa VPN

### Уровень 1: Программный мониторинг
- `KillSwitchService` отслеживает состояние VPN через platform channel
- При обнаружении разрыва показывает полноэкранное предупреждение
- Блокирует UI до восстановления VPN

### Уровень 2: Auto-reconnect
- `VpnServiceImpl` автоматически пытается переподключиться
- Мониторинг сети через `connectivity_plus`
- Дебаунс 2 секунды для нестабильных сетей

### Уровень 3: Системный (рекомендуется)
- На Android 12+: `VpnService.Builder.setBlocking(true)`
- На всех версиях: Always-on VPN + Lockdown mode

## Использование

### Включение Kill Switch

1. Откройте **Настройки**
2. Найдите **"Аварийное отключение"** (Kill Switch)
3. Включите переключатель
4. Подтвердите предупреждение

### Что происходит когда VPN отпадает

1. **Полноэкранное предупреждение** появляется немедленно
2. Весь UI блокируется
3. Показывается кнопка **"Try to Reconnect"**
4. Если переподключение не удалось — кнопка **"Disable Kill Switch"**

### Системный Kill Switch (рекомендуется)

Для максимальной защиты включите системный Kill Switch:

#### Android 12+:
1. Настройки → Сеть и интернет → VPN
2. Выберите Nexa VPN
3. Включите **"Всегда включён"**
4. Включите **"Блокировать соединения без VPN"**

#### Android 7-11:
1. Настройки → Подключения → VPN
2. Настройки (⚙️) рядом с Nexa VPN
3. Включите **"Всегда включать VPN"**
4. Включите **"Блокировать все соединения"**

### Platform Channel

**Канал:** `com.nexavpn.killswitch`

**Методы:**
- `enable()` — включить мониторинг
- `disable()` — выключить мониторинг
- `isSupported()` — проверка поддержки setBlocking
- `getAndroidVersion()` — версия Android

**Обратные вызовы:**
- `vpnDropped` — VPN внезапно отключился

### Файлы реализации

- `lib/services/killswitch_service.dart` — Dart сервис
- `lib/providers/killswitch_providers.dart` — Riverpod провайдеры
- `lib/widgets/killswitch/killswitch_warning.dart` — UI предупреждение
- `android/app/src/main/kotlin/com/nexavpn/nexa_vpn/KillSwitchService.kt` — нативный Android сервис
- `android/app/src/main/kotlin/com/nexavpn/nexa_vpn/MainActivity.kt` — регистрация channel

## Ограничения

### Программный Kill Switch
- ⚠️ Не блокирует трафик на уровне системы
- ⚠️ Приложения могут передать данные до появления предупреждения
- ⚠️ Задержка 100-500мс между разрывом и блокировкой

### Системный Kill Switch (Always-on VPN)
- ✅ Блокирует трафик на уровне ядра
- ✅ Нулевая задержка
- ⚠️ Требует Android 7+
- ⚠️ Пользователь должен включить вручную

### Android 12+ setBlocking
- ✅ Встроено в VpnService
- ✅ Работает автоматически
- ⚠️ Требует модификацию flutter_vless плагина (TODO)

## Тестирование

### Как протестировать Kill Switch:

1. **Включите Kill Switch** в настройках
2. **Подключите VPN**
3. **Выключите WiFi и мобильный интернет** одновременно
4. **Включите режим полёта**
5. **Наблюдайте:** должно появиться полноэкранное предупреждение
6. **Выключите режим полёта**
7. **VPN должен автоматически переподключиться**
8. **Предупреждение должно исчезнуть**
