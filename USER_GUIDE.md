# 📖 Руководство пользователя Nexa VPN

Добро пожаловать в Nexa VPN! Это руководство поможет вам настроить и использовать приложение.

---

## 🚀 Быстрый старт

### Установка APK

1. **Скачайте APK** с нашего сайта или получите от распространителя
2. **Разрешите установку** из неизвестных источников:
   - Настройки Android → Безопасность → Разрешить установку из этого источника
3. **Откройте скачанный файл** `nexa_vpn.apk` и нажмите "Установить"
4. **Запустите приложение** с рабочего стола

### Первое подключение

1. **Пройдите онбординг** — 2 приветственных слайда (показывается только один раз)
2. **Примите условия** использования и политику конфиденциальности
3. **Добавьте ключ доступа**:
   - Нажмите на главном экране → "Добавить ключ"
   - Вставьте ключ в формате:
     - `NEXA-XXXX-XXXX` (код активации)
     - `vless://...` (ссылка)
     - `https://...` (подписка)
4. **Выберите сервер** из списка (если доступно)
5. **Нажмите большую кнопку** на главном экране для подключения
6. **Разрешите VPN** в появившемся диалоге Android

✅ Готово! Вы подключены и защищены.

## 📱 Основные функции

### Главный экран

- **Большая кнопка** — подключение/отключение VPN
- **Статус соединения** — показывает текущее состояние
- **Статистика** — скорость загрузки/выгрузки, пинг, длительность сессии

### Серверы

- Просмотр всех доступных серверов
- Поиск по названию или хосту
- Переключение между серверами (с автоматическим переподключением)

### Мои ключи

- Просмотр активных ключей доступа
- Добавление новых ключей
- Удаление неиспользуемых ключей

### SOCKS5 Shield

**Уникальная функция Nexa VPN!**

Проверяет уязвимость локального SOCKS5-прокси:
- Откройте в меню → "SOCKS5 Shield"
- Нажмите "Сканировать"
- Приложение проверит, защищён ли прокси паролем
- Если нет — покажет рекомендации

### Настройки

- **Авто-подключение** — запуск VPN при старте приложения
- **Уведомления** — оповещения о подключении/отключении
- **Язык** — русский / английский
- **Тема** — тёмная / светлая (если доступно)

## 🔧 Решение проблем

### VPN не подключается

**Возможные причины:**

1. **Недействительный ключ**
   - Проверьте, что ключ не истёк
   - Убедитесь, что ключ введён полностью
   - Попробуйте другой ключ

2. **Проблемы с интернетом**
   - Проверьте подключение к интернету
   - Попробуйте переключиться между Wi-Fi и мобильной сетью
   - Перезапустите роутер

3. **Сервер недоступен**
   - Попробуйте другой сервер из списка
   - Подождите несколько минут и попробуйте снова

4. **Android блокирует VPN**
   - Некоторые производители блокируют VPN-сервисы
   - Проверьте настройки батареи → Разрешить фоновую активность для Nexa VPN
   - Проверьте настройки безопасности → Разрешить VPN

### VPN отключается сам

**Auto-reconnect работает автоматически**, но если связь не восстанавливается:

1. **Проверьте стабильность интернета**
   - Auto-reconnect срабатывает при восстановлении сети
   - Если интернет нестабильный — ожидайте периодические отключения

2. **Отключите энергосбережение**
   - Настройки → Батарея → Nexa VPN → Не оптимизировать
   - Это предотвратит "усыпление" VPN системой

3. **Проверьте другие VPN**
   - Если установлено другое VPN-приложение — отключите его
   - Android поддерживает только один активный VPN

### Медленная скорость

**VPN может замедлять интернет на 2-5%** — это нормально.

Если скорость значительно ниже:

1. **Смените сервер**
   - Выберите сервер ближе к вашему местоположению
   - Попробуйте разные серверы для лучшего результата

2. **Проверьте базовую скорость**
   - Отключите VPN и замерьте скорость
   - Сравните со скоростью через VPN
   - Разница более 20% — повод сменить сервер

3. **Перезапустите VPN**
   - Отключите и снова подключите
   - Это часто решает проблемы с "зависшими" соединениями

## 🔐 Безопасность

### Что мы НЕ храним:
- ❌ Логи вашей интернет-активности
- ❌ Историю браузинга
- ❌ DNS-запросы
- ❌ Исходный IP-адрес
- ❌ Контент передаваемых данных

### Что мы храним (необходимо для работы):
- ✅ Email (для управления аккаунтом)
- ✅ Хэш пароля (для аутентификации)
- ✅ ID устройств (для управления доступом)
- ✅ Даты подключений (для статистики)

### Рекомендации:
1. **Используйте сильный пароль** (если есть аккаунт)
2. **Не делитесь ключами доступа** с третьими лицами
3. **Обновляйте приложение** до последней версии
4. **Проверяйте SOCKS5 Shield** периодически

## ❓ FAQ

### Можно ли использовать на нескольких устройствах?
Да, количество устройств зависит от вашего ключа доступа. Управляйте устройствами через раздел "Мои устройства".

### VPN работает в фоновом режиме?
Да, Nexa VPN продолжает работать даже когда приложение свёрнуто. Android может "убивать" фоновые процессы — отключите оптимизацию батареи для Nexa VPN.

### Что такое vless:// ссылка?
Это формат ключа доступа, совместимый с протоколом VLESS. Вы можете импортировать ключи из других VPN-клиентов, если они используют этот формат.

### Нужен ли root для работы?
Нет, Nexa VPN работает без root-прав на любом Android 7.0+.

### Почему приложение запрашивает VPN permission?
Это стандартное разрешение Android для создания VPN-соединения. Без него VPN не может работать. Это не даёт приложению доступ к вашим данным — только возможность направлять трафик через зашифрованный туннель.
