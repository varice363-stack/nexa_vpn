## Full Description
```
Nexa VPN — это VPN-клиент нового поколения для Android. Мы сочетаем современный протокол VLESS с уникальной защитой SOCKS5, чтобы ваш трафик был действительно приватным.

🛡️ УНИКАЛЬНАЯ ЗАЩИТА SOCKS5
В отличие от других VPN, мы защищаем локальный SOCKS5-прокси паролем. Без этого любое приложение на устройстве может обойти VPN и раскрыть ваш реальный IP. Nexa VPN — первый клиент с такой защитой.

⚡ СКОРОСТЬ БЕЗ КОМПРОМИССОВ
Протокол VLESS поверх Xray REALITY — это современный стандарт. Быстрое подключение, стабильное соединение, поддержка всех популярных серверов.

🔒 ПОЛИТИКА НУЛЕВЫХ ЛОГОВ
Мы не храним историю посещений, DNS-запросы или содержимое трафика. Ваш Device Identity — единственный идентификатор, и он живёт только на вашем устройстве.

📱 УДОБНЫЙ ИНТЕРФЕЙС
Чистый дизайн, один клик для подключения, умный выбор сервера. Работает в фоне, не разряжает батарею.

 СЕРВЕРЫ ПО ВСЕМУ МИРУ
Десятки локаций: Европа, Азия, Америка. Автоматический выбор лучшего сервера по задержке.

🔑 ПРОСТОЙ ДОСТУП
Никакой регистрации по email. Код устройства — ваш ключ. Потеряли телефон? Восстановите доступ по коду.

💳 ГИБКИЕ ТАРИФЫ
• Бесплатный пробный период 7 дней
• Подписка от 199₽/месяц
• Оплата через ЮKassa (карты РФ, СБП)

⚙️ ТЕХНИЧЕСКИЕ ДЕТАЛИ
• Протокол: VLESS + Xray REALITY
• Локальный прокси: SOCKS5 с парольной защитой
• Шифрование: AES-256-GCM
• Платформа: Android 7.0+
• Размер APK: ~25 МБ

⚠️ ВАЖНО
Использование Nexa VPN требует принятия условий VpnService. Приложение запрашивает разрешение на создание VPN-соединения — это стандартное требование Android для любого VPN-клиента.
```
